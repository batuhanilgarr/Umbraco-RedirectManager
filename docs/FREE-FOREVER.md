# Free Forever Promise

BT.RedirectManager is open source and will stay useful for free. If paid editions ever exist, these
commitments protect everyone who already relies on the free package. They apply to the maintainer, Batuhan
Tugberk Ilgar, and to every release of the `BT.RedirectManager` package.

1. **What you have today stays free.** Every feature that ships in versions up to and including 1.11.x stays
   available under the [MIT license](../LICENSE), free of charge. Published versions can never be re-licensed
   or withdrawn.

2. **No clawback.** A feature that exists in the free package is never removed, limited, rate-capped or moved
   behind a paywall. If a free feature is improved, the free behavior stays free; anything paid is a new layer
   on top, never a replacement.

3. **The core stays open source.** Future versions of `BT.RedirectManager` will not move to a more restrictive
   license than MIT. If the project is ever abandoned, you are free to fork it.

4. **It keeps working with Umbraco.** The free package stays compatible with every Umbraco version inside
   Umbraco's own support window (currently 13 until its end of life in December 2026, then 17, 18 and later
   releases), and security fixes are published for it. After a version reaches Umbraco's end of life, support
   for that Umbraco version moves to best effort (critical fixes only).

5. **No license is ever needed.** Installing or upgrading the free package never requires a key, never phones
   home to check one, and never disables anything. A paid edition, if it exists, is a separate package with its
   own license. The free dashboard may show a single dismissible notice about it, nothing more.

6. **Paid features can never break your redirects.** Redirect resolution does not depend on any license. If a
   paid package's license is missing, invalid or expired, only that package's own extra features stop; your
   redirects keep working.

7. **Telemetry is opt-in.** Usage pings stay off by default and are never required. See the README's Telemetry
   section for exactly what is sent.

## How this can change

This promise can only get stronger for already-published versions. Any change to how future releases are
licensed or packaged will be announced in the release notes at least one minor version ahead, and can never
reach back to take away what a published version already gave you.

Questions or concerns: open an issue at
<https://github.com/batuhanilgarr/Umbraco-RedirectManager/issues>.
