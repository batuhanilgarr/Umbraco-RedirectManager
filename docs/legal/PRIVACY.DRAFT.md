## Product telemetry (opt-in)
The open-source package can send an anonymous usage ping only if you turn it on. It contains a random site ID,
package and Umbraco versions, and feature counters. No redirect URLs, visitor data or personal data. The
endpoint is a Cloudflare Worker with a D1 database. Turn it off any time in configuration.

and does not send redirect or 404 contents to the Licensor.
