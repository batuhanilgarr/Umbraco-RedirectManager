Bitiz Redirect Manager

This panel lets you centrally manage URL redirects for your site. You can add new redirects, update existing ones, or remove rules that are no longer needed.

Status Code Descriptions:

301 Permanent Redirect - Tells browsers and search engines to always use the new URL
302 Temporary Redirect - Temporarily redirects traffic to another URL
404 Not Found - Returns a standard 404 "Page not found" response
410 Gone - Indicates the page has been permanently removed
